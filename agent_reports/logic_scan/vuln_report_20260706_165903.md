## 确认漏洞（PoC / 代码流 / 修复代码）

### [1] CWE-639 — `idorpv_182`
> LessonInfoService.getLessonInfo 允许未授权用户通过路径变量枚举任意课程信息，无所有权校验、无会话绑定、无租户/用户上下文过滤，构成 CWE-639（水平越权）。

#### 证据层级
| L1 | present | L2 | partial | L3 | not_verified |

#### 代码/调用流
HTTP GET /service/lessoninfo.mvc/{lesson} [src/main/java/org/owasp/webgoat/container/service/LessonInfoService.java:20] → LessonInfoService.getLessonInfo() → course.getLessonByName(lessonName) [src/main/java/org/owasp/webgoat/container/session/Course.java:?] → 返回 LessonInfoModel（含 title 和三个布尔标志）

#### 漏洞利用（PoC）
1. 使用任意已登录 WebGoat 用户（如 guest/password）获取有效 JSESSIONID；
2. 发送请求：curl -X GET 'http://localhost:8080/service/lessoninfo.mvc/access-control' -H 'Cookie: JSESSIONID=ABC123...'；
3. 观察响应：{ "title": "Access Control", "completed": false, "hidden": false, "locked": false }
4. 替换路径变量为其他课程名（如 'idor', 'jwt', 'sql-injection'），重复请求；
5. 成功获取所有课程标题与状态（包括未解锁/隐藏课程），证明水平越权。
