### [1] CWE-639 — `idorpv_182`
> LessonInfoService.getLessonInfo 接口通过 /service/lessoninfo.mvc/{lesson} 暴露 lesson 名称路径变量，未校验当前用户是否有权访问该 lesson，且 lessonName 为外部可控输入；course.getLessonByName() 返回任意 lesson 实例，构造 LessonInfoModel 时未绑定用户会话或权限上下文，构成水平越权（CWE-639）。

#### 证据层级
| L1 | present | L2 | partial | L3 | not_verified |

#### 代码/调用流
HTTP GET /service/lessoninfo.mvc/{lesson} [LessonInfoService.java:20] → LessonInfoService.getLessonInfo() [LessonInfoService.java:20] → course.getLessonByName(lessonName) [Course.java:?] → returns Lesson instance → new LessonInfoModel(lesson.getTitle(), false, false, false) [LessonInfoService.java:24]

#### 漏洞利用（PoC）
1. 启动 WebGoat（默认 http://localhost:8080）
2. 不登录或使用任意低权限账户（如 guest/guest）

import org.springframework.security.core.Authentication;
import org.springframework.security.core.context.SecurityContextHolder;

@PostMapping("jku/follow/{user}")
public @ResponseBody String follow(@PathVariable("user") String user) {
    Authentication auth = SecurityContextHolder.getContext().getAuthentication();
    if (auth == null || auth.getPrincipal() == null) {
        return "Not authenticated";
    }
    String currentUsername = auth.getName();
    if ("Jerry".equals(user)) {
        return "Following yourself seems redundant";
    } else if (!"Tom".equals(user)) {
        return "You can only follow Tom";
    } else if ("Jerry".equals(currentUsername)) {
        return "Jerry is not allowed to follow Tom";
    } else {
        return "You are now following Tom";
    }
}
