## 确认漏洞（PoC / 代码流 / 修复代码）

### [1] CWE-639 — `idorpv_182`
> LessonInfoService.getLessonInfo 存在水平越权 IDOR（CWE-639）：通过路径变量 /service/lessoninfo.mvc/{lesson} 可任意枚举课程名访问任意课程元信息，服务端未校验当前用户是否被授权访问该课程。

#### 证据层级
| L1 | present | L2 | partial | L3 | not_verified |

#### 代码/调用流
HTTP GET /service/lessoninfo.mvc/{lesson} [LessonInfoService.java:20] → LessonInfoService.getLessonInfo(@PathVariable lessonName) [LessonInfoService.java:20] → course.getLessonByName(lessonName) [Course.java:?] → returns Lesson object → constructs LessonInfoModel with title and static booleans

#### 漏洞利用（PoC）
1. 启动 WebGoat 应用（默认 http://localhost:8080）
2. 无需登录（该端点匿名可访问）
3. 执行以下 curl 命令枚举课程信息：
   curl -X GET '{BASE_URL}/service/lessoninfo.mvc/sql-injection'
   curl -X GET '{BASE_URL}/service/lessoninfo.mvc/xss'
   curl -X GET '{BASE_URL}/service/lessoninfo.mvc/jwt'
预期结果：返回 JSON 如 {"title":"SQL Injection","completed":false,"inProgress":false,"locked":false}，即使当前用户未解锁或未登录，也能获取所有课程元数据，包括未授权课程的存在性与状态。
